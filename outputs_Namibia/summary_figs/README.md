This folder contains a set of summary plots for the key results of the illustrative Namibian case study.

This set includes the following plots:
- Development of total population, average income level, and corresponding average residential electricity demand under different Shared Socioeconomic Pathways (SSPs) over the transition period. See **summary_stats_pop_inc_elec.png**.
- Breakdown of total population and residential electricity demand by MTF tier for the year 2050, all populated cells. See **summary_stats_byMTF.png**.
- Breakdown of total population and residential electricity demand by MTF tier over the transition period, currently un-electrified populated cells only. See **summary_stats_byMTF_(2025...2050)_unelectrified.png**.
- High-resolution distribution of average residential electricity demand colour-coded by MTF tier for the years 2025 and 2050 under SSP1, currently un-electrified populated cells only. See **demand_dist_SSP1_2550_unelectrified.png**
- Regional (first administrative level) distribution of average residential electricity demand colour-coded by MTF tier for the year 2050 across SSPs 1-3, currently un-electrified populated cells only. See **DemandDist_regional_SSP123_2050.png**.

This set only serves as an example of what kind of summary plots can be generated. The user can flexibly generate other kinds of plots from the output data as needed.
