The main output files of this tool are as follows:
- High-resolution geospatial rasters of projected population count by scenario and year, see **rasters_POP** folder.
- High-resolution geospatial rasters of projected income level by scenario and year, see **rasters_INC** folder.
- High-resolution geospatial rasters of projected residential electricity demand per capita by scenario and year, see **rasters_perCapitaElec** folder.
- High-resolution geospatial rasters of projected total residential electricity demand by scenario and year, see **rasters_TotElec** folder.
- High-resolution geospatial rasters of projected electricity demand tiers according to the Multi-Tier Framework by scenario and year, see **rasters_MTF** folder.

Additional output files include:
- Re-sampled and aligned GDP and nighttime lights geospatial rasters for the base year, see **aligned_GDP** and **nighttime_lights** folders.
- Residential electricity demand per capita and income level correlation diagram based on global statistics, see **corr_fig** folder.
- Summary line, bar, and map plots for key results, see **summary_figs** folder.
