This is the second set of main output files. The set comprises a number of high-resolution geospatial rasters of projected income level for the study region. Each file corresponds to a certain socio-economic development scenario. Each of the files has a number of bands, each corresponding to a certain transition year.

**N.B.** The socio-economic development scenarios used in this illustrative case study for Namibia are the 5 Shared Socioeconomic Pathways. The modelled transition period is 2025-2050 in 5-year intervals. However, you can flexibly use other socio-economic development scenarios and model different transition years.
