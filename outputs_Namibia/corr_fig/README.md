This figure shows the correlation between residential electricity demand and income level, i.e. GDP per capita.

The correlation has been derived using a two-term exponential regression function based on global statistics for the year 2014.
The raw data used to generate this figure can be found under **inputs/excel-files**.

This correlation is used to estimate the residential electricity demand of each populated cell in the study region based on its income level.

In the main script, the user can flexibly update the figure (and correlation) based on more recent data and/or different regression functions.
