The main output files of this tool are as follows:
- High-resolution geospatial rasters of projected electricity access status by scenario and year, see **ElecStat_rasters** folder.
- High-resolution geospatial rasters of projected residential electricity demand per capita by scenario and year, see **perCapitaElec_rasters** folder.
- High-resolution geospatial rasters of projected total residential electricity demand by scenario and year, see **TotElec_rasters** folder.
- High-resolution geospatial rasters of projected electricity demand tiers according to the Multi-Tier Framework by scenario and year, see **MTF_rasters** folder.

Additionally, the geopackage files in **elec_proj** provide information on the projected socioeconomic indicators; population, income level, and total GDP, for each populated cell.

Currently, these folders are empty but will be populated with output files when the script "4_elecdem_projection" is run.

The output from Namibia's case study can be accessed from [Google Drive](https://drive.google.com/drive/folders/1iYg59zg_wSVj7NX3q0NNo4TE4hRYkv6S?usp=sharing) due to size restrictions on GitHub.
